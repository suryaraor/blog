IMPLEMENTATION NOTES:

PowerShell Encoding Fix (Critical for this repository):

The specific mojibake issue found in these posts is a multi-byte sequence corruption pattern.

To fix in PowerShell:

$mojibake = [byte[]]@(0xC3, 0x83, 0xC6, 0x92, 0xC3, 0x82, 0xC2, 0xA2, 0xC3, 0x83, 0xC2, 0xA2, 0xC3, 0xA2, 0xE2, 0x82, 0xAC, 0xC5, 0xA1, 0xC3, 0x82, 0xC2, 0xAC, 0xC3, 0xA2, 0xE2, 0x82, 0xAC, 0xC2, 0x9D)

$emdash = [byte[]]@(0xE2, 0x80, 0x93)

$bytes = [System.IO.File]::ReadAllBytes("path/to/file.md")

$str = [System.Text.Encoding]::UTF8.GetString($bytes)

$mojStr = [System.Text.Encoding]::UTF8.GetString($mojibake)

$emStr = [System.Text.Encoding]::UTF8.GetString($emdash)

$fixed = $str.Replace($mojStr, $emStr)

[System.IO.File]::WriteAllBytes("path/to/file.md", [System.Text.Encoding]::UTF8.GetBytes($fixed))

Note: Always use System.Text.UTF8Encoding($false) to save without BOM.
